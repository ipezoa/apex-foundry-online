# Apex Foundry v4 circuit pack

These 25 JSON files are already built into the v4 game. To load one separately, use Track Lab → Import and select its JSON file. Requires v4 or later (mapped geometry / schema version 2). Old custom JSON files remain supported in v4.

The original route is fixed; road widths, runoff, banking/elevation offsets, overall scale and direction remain editable. Every circuit uses 48 editing zones, not 48 official corners. Source metadata records provenance and inferred dimensions. See CIRCUITS.md and the accompanying geographic-data MIT notice.

The original Formula Timer artwork is not embedded. The game supplies original offline map diagrams and optional links to the original images. Track dimensions and other source facts are attributed snapshots from 4 November 2026, not full surveyed replicas.
